# dsh-life-state

给 [dsh-qqbot](https://github.com/Oblivious0214/dsh-qqbot) 的 QQ Bot 会话注入「角色的一天」——**主人不在时，角色也在过日子**：三餐、午睡、家务、偶尔的小倒霉，都会被记录并自然地带进对话。

## 效果

每轮拼提示词时，插件会把类似下面这几行写进会话的 `qqbot:runtime` context（发给模型、但你收到的消息里看不见）：

```
今日生活：早餐=蛋炒饭；午睡=40 分钟；家务=洗围裙。
今天还没跟你提过的：把围裙洗了晾在阳台上。
前些天：前天洗围裙、昨天剩汤浇饭。
```

- **零成本**：所有内容都是本地随机（`Math.random`）抽的，不调模型、不花 token、不往会话发消息。
- **惰性补齐**：到点才抽、未来留空——上午 10 点只会有早餐，绝不会冒出「午睡睡了三十分钟」。
- **不带心情**：情绪不写进文件，让角色按「距上次对话」自己推（配合 [dsh-time-awareness](https://github.com/MY-uan/dsh-time-awareness)）。
- **事件冷却**：同一件家务几天内不重复（洗围裙 3 天、米桶补满 7 天），不会天天洗围裙。
- **连续性**：留最近 7 天历史，隔天开新会话也能说「前天洗的围裙」。

## 事件池与约束

| 项 | 内容 |
|---|---|
| 三餐 | 白饭配咸鱼 / 蛋炒饭 / 两个饭团 / 剩汤浇饭（随机抽） |
| 午睡 | 随机 20~60 分钟 |
| 家务 | 洗围裙 / 擦桌子 / 晾衣服 / 把米桶补满（一天一件，带冷却） |
| 小倒霉 | 把米洒了一地 / 尾巴撞到桌角（一天最多一次，概率约 15%，**只限角色自己、不碰主人的东西**） |

跨天自动重置；每时段一天只生成一次。

## 状态文件

`<DSH_HOME>/qqbot/life-state.json`，纯文本 JSON，可直接打开看、可手动改：

```json
{
  "date": "2026-11-04",
  "slots": { "breakfast": "蛋炒饭", "lunch": null, "nap": "40 分钟", "dinner": null, "chore": "洗围裙", "mishap": "" },
  "report": { "text": "把围裙洗了晾在阳台上", "mentioned": false },
  "history": [ { "date": "2026-11-02", "event": "洗围裙", "category": "chore", "at": 1234567890 } ]
}
```

## 安装

跟你装 `dsh-time-awareness` 一模一样：

1. 把整个 `dsh-life-state` 文件夹推到你的 GitHub 仓库；
2. DSH → 插件 → 添加插件 → 粘贴 `https://github.com/<你的用户名>/dsh-life-state` → 安装；
3. 完整退出 DSH 再重开。

装完重启后，打开 QQ Bot 会话 → 顶部「提示词」标签 → 在 runtime context 里应该能看到 `life-state: 今日生活…` 那一行（早上装的话可能只有早餐，其余时段等到了点才补）。

## 可调参数（lib/index.js 顶部）

| 常量 | 默认 | 说明 |
|---|---|---|
| `SLOT_MINUTES` | 早餐8点/家务10点/午餐12点/午睡14点/倒霉16点/晚餐18点 | 各时段「到点」时间 |
| `MISHAP_CHANCE` | 0.15 | 小倒霉概率 |
| `HISTORY_DAYS` | 7 | 历史保留天数 |
| `RETURN_GAP_MS` | 30 分钟 | 汇报位「回来才提」的间隔阈值 |

## 说明与限制

- 状态文件是**全局一份**（一个角色一天一份），多会话同时读写时以最后一次写盘为准；
- 汇报位是**一次性**的：注入一次就标记「已提」，之后不再重复；
- 情绪由角色自己按「距上次对话」推，插件不写死心情。
