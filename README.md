# dsh-life-state

给 [dsh-qqbot](https://github.com/Oblivious0214/dsh-qqbot) 的 QQ Bot 会话注入「角色的一天」——**主人不在时，角色也在过日子**。按五个时段惰性生成三餐/午睡/家务/小倒霉/睡前小事，动作化、可连链、允许留空，并自然地带进对话。

## 效果

每轮拼提示词时，插件会把类似下面这行写进 `qqbot:runtime` context（发给模型、但你收到的消息里看不见）：

```
今日：早晨 煎了两个蛋配剩饭；把昨晚的碗刷了。午后 洗了围裙，晾在阳台。
今天还没跟你提过的：把晾着的围裙收进来叠好了。
前些天：昨天洗围裙、前天补米桶。
```

- **零成本**：全部本地随机（`Math.random`），不调模型、不花 token、不发消息。
- **五个时段惰性补齐**：早晨 6–11 / 中午 11–15 / 下午 15–18 / 傍晚 18–23 / 深夜 23–6，只补「已过去且空着」的，未来留空。
- **动作化**：给「动作」不给「结果」——不是「晚餐=剩汤浇饭」，而是「把剩汤浇在饭上热了热」。
- **允许留空**：下午、傍晚心情、深夜各有概率"什么都没发生"，不是每个钟头都有故事。
- **能连成链**：洗围裙 →（次日）收围裙，后一个只有前一个出现过才可抽。
- **注入克制**：只渲最近两三条，不五个时段全倒；情绪用"动作化瞬间"、不给硬标签。
- **回来可提**：当天最值得顺口说出口的一件事，只一条、提过就锁。

## 状态文件

`<DSH_HOME>/qqbot/life-state.json`，纯文本 JSON，可直接打开看、可手动改：

```json
{
  "date": "2026-11-11",
  "periods": { "morning": "煎了两个蛋…", "noon": "扒了碗蛋炒饭…", "afternoon": "", "evening": "煮了碗面…", "latenight": "" },
  "report": { "text": "把晾着的围裙收进来叠好", "mentioned": false },
  "history": [ { "date": "2026-11-10", "event": "洗围裙", "category": "chore", "at": 1234567890 } ]
}
```

> 「生活日」从早晨 6:00 起算：凌晨 0–6 点仍属于前一天（那是"深夜"时段）。

## 安装

跟你装 `dsh-time-awareness` 一模一样：

1. 把整个 `dsh-life-state` 文件夹推到你的 GitHub 仓库；
2. DSH → 插件 → 添加插件 → 粘贴 `https://github.com/<你的用户名>/dsh-life-state` → 安装；
3. 完整退出 DSH 再重开。

装完重启后，打开 QQ Bot 会话 → 顶部「提示词」标签 → runtime context 里应能看到 `life-state: 今日：…`。

## 可调参数（lib/index.js 顶部）

| 常量 | 默认 | 说明 |
|---|---|---|
| `PERIODS` | 早晨6–11/中午11–15/下午15–18/傍晚18–23/深夜23–6 | 五个时段的结束时间 |
| `EMPTY_CHANCE` | 下午0.3/傍晚0.1/深夜0.4 | 各时段"留空"的概率 |
| `MISHAP_CHANCE` | 0.15 | 下午掺入小倒霉的概率 |
| `HISTORY_DAYS` | 7 | 历史保留天数（用于冷却 + 连链 + 连续性） |
| `RETURN_GAP_MS` | 30 分钟 | 汇报位「回来才提」的间隔阈值 |

事件池（三餐/家务/小倒霉/睡前小事）都写在代码顶部，想加料直接改数组即可。

## 说明与限制

- 状态文件是全局一份（一个角色一天一份），多会话同时读写以最后一次写盘为准；
- 汇报位是一次性的：注入一次就标记「已提」；
- 情绪由角色自己按「距上次对话」推，插件的"心情"只是动作化的瞬间、不给硬标签。
